Speedreader is a code modeled after the previous free version of spreeder from back in the day.
//////Category//////
Productivity Tools

//////Core Function//////
Text reader that converts input text to readable chuncks, with our without filler words, to assist in faster reading speeds for the end user.

//////Functionality//////
WPM: The user can input the speed at which they wish to read words per min, with a default of 200 wpm.

Font size: Users can deterine the sizing of words for optimal reading.

Words per Chunk: This function enables the user to adjust how many words they prefer to read at once.

Include filler words: Checkbox to wether or not to include common filler words (i.e. the, and, thus, and more)

Start reading button: Starts from the first word and onwards. This button also restarts the reading process.

//////Keyboard Controls//////
Reading speed: Alt+1 = decrease / Alt+2 = increase

Word Chunk Size :Alt+3 = decrease / Alt+4 = increase

Font size: Alt+5 = decrease / Alt+6 = increase 

Pause/Resume/Restart: Space
